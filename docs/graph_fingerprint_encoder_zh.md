# 图与固定指纹的分子残差组件

对应预登记[A09](../attempt_9.md)，组件、组合读取器和`gine_fingerprint`正式入口/完成
审计接入已通过合成检查。真实输入预检与最终parent绑定仍待，尚无正式训练或模型收益；
A07固定源码与A08等待队列均不使用此组件。

实现位于`SpecEmbedding/models_graph_fingerprint.py`。谱图塔、投影头、对比损失接口和
最终余弦检索继承parent；分子塔先保留GINE消息传递、mean pooling及原规模特征融合，
然后把固定Morgan位向量经小型MLP得到的残差加到分子表示上，再进入原分子投影头。

```text
规范分子图 → 原GINE → 原128维分子表示 ─────────┐
                                             加法 → 原分子投影 → 共享嵌入
固定2048位指纹 → Linear256 → LN → GELU → Linear128 ┘
```

`params.yaml`的`graph_fingerprint_residual`是未激活的组件设置，要求显式给定
`input_bits`、`hidden_dim`和`norm_eps`。目前预登记2048、256和1e-5；按128维GINE
输出实际增加557,952参数，真实parent条件构造的总参数见A09实验卡。没有额外dropout，
末层权重/bias为0；分支构造使用隔离的CPU随机状态，原两塔权重、后续随机状态和零残差
时输出保持一致。构造顺序与真实fresh训练入口一致：先分子塔，再谱图塔和投影头；
测试直接捕获`train_align`构造的parent模型，不用checkpoint重构器的顺序代替训练。
此兼容性不等同于收敛或检索收益保证。

新增参数属于`mol_encoder`，原训练优化器的参数分组能够覆盖；两步合成更新检查了首步
末层以及后续隐藏层、GINE、谱图塔和投影头梯度。`encode_mol`只读取分子图及其指纹，
不使用当前谱图、真值标签或其它候选，仍可按分子独立编码并分块处理。

组件输入为PyG batch上的`fingerprints`浮点二维张量，每个图一行、列数等于设置位宽。
组件拒绝缺失、错误行数/位宽、非浮点或不同设备输入；位值及语义行身份由固定输入读取器
核验，不能凭张量形状认定分子身份正确。测试已确认打乱指纹行会改变激活分支后的输出。

`SpecEmbedding/data/datasets_graph_fingerprint.py`保留原完整谱图读取、图增强及自然负例
采样，按精确目标SMILES或负例的全局分子行号读取原始指纹；只保留目标查询字典，避免
每个worker复制全部候选映射。原PyG collate会把每个图的指纹沿行维拼接，设备迁移随图
一起完成；训练图缓存不附加增强结果或可变指纹，不因新分支改变采样RNG。

`SpecEmbedding/utils/graph_fingerprint_validation.py`要求图/指纹缓存绑定相同数据、
索引及完整分子顺序；图缓存可省略而直接规范构图。验证沿用完整候选和二维标签，指纹
碰撞不合并身份；每次调用重新编码两塔，并把两类缓存来源写入排名快照，供既有
`audit_snapshot`核对。正式完成审计还会核验manifest/selection、完整来源文件、候选重放、
轨迹、资源和严格权重重载；不能只用快照检查宣称正式实验完成。

图与指纹构造规则不变；保留既有图增强，指纹仍描述原始分子。只有规范图、指纹参数或
来源索引改变才重建对应固定缓存，不重建未受影响的输入，不清理活跃引用。所有学习
embedding随模型权重重新编码，不能复用A04/A06缓存向量或融合其已保存分数。

`construction_config()`返回独立副本，包含新模型类型、完整parent构造和指纹残差设置。
合成严格重载要求全部新增权重，不允许缺失时默默置零。正式入口使用
`--molecule-input gine_fingerprint`及完整三项指纹路径，训练/验证同时保留适用图缓存，
把两类输入来源写入manifest/selection。比较基线从自身checkpoint构造，并按自身类型
选择图、指纹或两者；纯指纹基线不接收图缓存，新模型不会因此丢失自己的图输入。
真实小型入口训练与完整审计合成检查已通过，全量真实预检仍待；现阶段不会自动触发A09，
也没有GPU资源或MassSpecGym完整检索测量。
