## 1. 修改目标与动机

将论文从“实验协议、artifact provenance 和不可声称事项的审计报告”改回一篇结构完整、定位克制的方法论文。

论文主线改为：

> 在固定的跨模态候选检索结果内，使用监督式 coarse-to-fine reranker 学习候选优先级；本文提出一个无 rank、无 positive forcing、具有反对称候选关系的 spectrum-conditioned relative reranker，并用容量匹配的 pointwise scorer 检验候选关系是否提供额外收益。

当前证据足以支持“监督式二阶段 reranking framework”这一方法论文定位，但不支持宣称 relative 模块稳定优于 pointwise。因此，重写后应把 relative 作为明确提出和形式化的方法机制，把 pointwise 结果作为重要的受控发现，而不是回避或人为解释为 relative 的优势。

## 2. 当前证据与问题定位

### 2.1 可以保留为方法论文主体的内容

- 问题定义清楚：在 mass-或 formula-conditioned 的固定候选池内进行闭集重排序。
- 方法结构完整：跨模态 alignment、候选池 coarse scoring、coarse top-40 relative refinement。
- relative 分支有具体输入、关系权重、候选对偏好和最终分数公式。
- `p_{ij}=g(\rho_{ij})-g(\rho_{ji})` 给出参数无关的 pair antisymmetry；共享候选维度运算给出候选置换等变性。
- 训练目标包括 listwise、pairwise 和 spectrum-dependency 项；模型复杂度有 $O(Kd)+O(K_r^2d)$ 的结构说明。
- 有容量匹配的 no-rank pointwise control、主结果、信息来源控制、难例分层和限制性讨论。

### 2.2 需要通过叙事重写解决的问题

- 当前摘要、引言、贡献和实验段落反复强调 candidate order、identity、artifact 和 audit，削弱了方法问题、方法设计和实验发现。
- `Table 1` 仍把当前方法写成 “Optional candidate self-attention”，与正式的 antisymmetric relative pair module 不一致。
- 主结果显示 pointwise 在两个候选池的主要 R@1/MRR 汇总略高于 relative。该事实应成为方法分析的一部分，而不是通过增加审计或额外机制解释来回避。
- 当前论文将“监督 reranking 的有效性”和“relative relation 的独立收益”混在同一条叙事中；二者必须分开。
- 历史 Transformer、旧 forcing 协议和详细 artifact provenance 在正文中占据过多注意力，应压缩为必要的对照或限制说明。

## 5. 具体内容设计

### 5.1 标题、摘要与引言

标题改为范围更明确的 `Supervised Non-Generative Reranking for Fixed-Candidate MS/MS Molecule Retrieval`，正文继续形式化 relative 机制，但不暗示 relative 已经取得独立性能优势。

摘要按以下顺序组织：

1. MS/MS 候选池中存在 hard candidates；
2. 固定跨模态检索结果后的二阶段排序是本文问题；
3. 提出 coarse-to-fine、rank-free、no-forcing 的 relative reranker；
4. 用容量匹配 pointwise control 检验关系模块；
5. 现有结果表明两种监督 reranker 都改善 base，而 pointwise 在主要 R@1/MRR 汇总略高，relative 的独立收益尚未确立；
6. 论文贡献是方法框架及其受控分析，不是 SOTA 或 relative 优势声明。

引言只保留问题动机、与现有 cross-modal similarity/generative retrieval 的差别、本文方法和三条贡献。候选顺序重建、身份审计、旧提交和发布材料不放入引言。

贡献建议改为：

- 提出固定候选池内的非生成式 coarse-to-fine supervised reranking framework；
- 形式化一个 spectrum-conditioned、rank-free、antisymmetric、permutation-equivariant 的 candidate relation module，并给出 pointwise capacity control；
- 在 MassSpecGym 两类候选协议上报告监督 reranking 的效果及 relative 与 pointwise 的边界性比较。

1. 固定候选池和 coverage upper bound；

需要明确说明：spectrum-conditioned 的条件来自冻结的 spectrum embedding；当前 reranker 不直接使用 raw peaks、formula、adduct 或采集元数据。这是当前方法的输入边界，不需要通过新增领域特征来补救。

### 5.4 实验与结果

实验章节围绕“方法是否有效、relative 是否提供额外信息”组织，而不是围绕“如何完成审计”组织：

### 5.6 讨论、局限性与结论

讨论只回答三个问题：

1. 监督式二阶段 reranking 相对 base 的价值是什么；
2. 当前 relative 机制是否得到独立收益；
3. 该结论受哪些方法边界限制。

正文局限性压缩为：5,000-query pilot、单 alignment checkpoint、saved-embedding official-compatible scope、closed-library/formula-conditioned setting、外部 baseline 未复现和未验证跨数据集泛化。具体协议和发布边界引用 Appendix A/D，不把正文限制性章节写成发布验收清单。

结论应明确：本文提出并分析一个方法框架；当前实验支持监督 reranking 的框架级有效性，但不支持 relative 模块独立普遍优于 pointwise 的结论。
