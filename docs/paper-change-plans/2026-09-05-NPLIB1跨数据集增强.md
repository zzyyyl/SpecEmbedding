## 1. 修改目标与动机

在第二套 NPLIB1/CANOPUS 派生协议上比较 Base、Pointwise 和 Relative，区分候选 coverage、
基础检索与二阶段排序的影响。NPLIB1 与 MassSpecGym 有明显身份重叠，因此主实验定位为
NPLIB1 in-domain 重训；去重后的 zero-shot 只作小样本敏感性分析，不支持独立外部泛化主张。

## 2. 当前证据与问题定位

来源、固定版本、checksum、处理统计及实际工件路径统一见
[数据来源记录](../../reproducibility/nplib1-data-sources.yaml)，存储根为
`/data1/zyl/SpecEmbedding/`。基线提交为 `6eb367b`，计划启动提交为 `22351e3`。

- 原始 split 的 train/validation 共享 74 个二维身份；test 与二者无身份交集。
- `cand_dict_train_updated.pkl` 是训练正则化负池，7,127 个 query 的精确真值 coverage 为 0；
  不能与 test retrieval 候选合并，也不能通过 forcing 补成训练集。
- 官方 test `cand_dict_large.pkl` 与从固定 `mol_dict.pkl` 重建的全 split 分子式候选是不同协议。
- 已处理数据为 train/val/test 7,601/344/879 条谱图，派生划分二维身份交集为 0。
  NPLIB1 test 中 726 条谱图与 MassSpecGym train 共享二维身份；严格排除后剩 153 条谱图、
  139 个结构。另有 2 个 train/test 跨身份相同谱峰签名，正式报告前仍须逐条核验。

## 3. 修改范围

### 3.1 涉及文件与章节

- 已实现：NPLIB1 原始处理、validation 去重、formula/supplied 候选、provider/pipeline

- 待完成：正式运行的 `analysis/` 聚合及 `reproducibility/` provenance；依据结果同步双语稿、

### 3.2 明确不做的事项

不使用商业 NIST 数据，不把不同文件名当成数据独立性，不逐 query 插入真值，不按结果挑选
seed/指标或删除负结果。不把保存嵌入审计、CPU pilot 或去重小样本写成正式泛化证据。
不声称 SOTA、显著性、relative 独立优势或完整 official-loader 复现。

## 4. 已确认的协议

1. **划分与身份**：使用二维 InChIKey，保留原 SMILES、规范 SMILES 和完整身份用于核验。
   用户于 9 月 5 日确认从 validation 移除与 train 重叠的 74 个身份，train/test 不变；
   称 derived de-overlapped validation，不称原样官方 structure-disjoint split。
2. **候选**：用户同日确认，从冻结的官方 `mol_dict.pkl` 按分子式一致构建 train/val/test
   候选。真值只能作为固定库自然成员，不逐 query 插入。保存库/候选哈希、分子式算法、无效分子、
   候选顺序、规模、过滤与 coverage；`candidates_supplied.pkl` 单独保留为 test-only 协议。
3. **训练与评价**：Base top-256、relative coarse top-40、全部 split no-forcing。训练只用自然
   有标签 query；无正例评价 query 仍进入指标并计 coverage miss，报告 pre-top-K upper bound。
   正式训练使用完整可训练集和显式 CUDA 设备；GPU 忙则等待，不回退 CPU。
4. **重叠审计**：分别核对各 split 的二维身份、规范 SMILES、精确谱峰签名及可行的结构近邻
   分布。zero-shot 至少排除与 MassSpecGym train 的二维身份重叠，in-domain/zero-shot 分表。
5. **正式矩阵**：NPLIB1 alignment seeds 42--44，各自训练 Pointwise/Relative reranker
   seeds 42--44；指标为 R@1/5/10/20、MRR、coverage、Base top-K upper bound。按 alignment
   分层报告均值/样本 SD 和配对差，不把 3 seeds 当作显著性证据。
6. **迁移与范围**：zero-shot 使用冻结的 MassSpecGym checkpoint；输入协议不兼容则记录
   不可比较原因。NPLIB1 不重复完整 30-run 消融，除非主比较出现必须解释的新机制问题。
7. **论文门槛**：据真实结果描述两套协议内的收益或数据集依赖，不升级为独立外部泛化；
   relative 的独立收益须有预注册配对的一致方向与充分证据。模型选择不访问测试结果。

- 数据：来源、许可、size/checksum、划分与重叠、候选顺序/正例 cardinality 和 coverage。

- 论文：双语内容、数字、引用、限制一致；`bash paper/build_release.sh`、页数/警告/哈希和匿名检查。
