## 1. 修改目标与动机

本计划回应导师关于论文科学问题、方法解释、实验规模、化学案例、外部比较、效率讨论、叙事风格和贡献表述的意见。总目标不是把 relative 模型包装成优于 pointwise 的方法，而是把现有结果组织成一个清晰、克制且可辩护的方法论文：

> 在固定跨模态候选池内，监督式第二阶段重排序是否有效，以及候选间相对关系建模是否能在容量匹配的 pointwise 打分之外提供稳定的额外收益？

论文需要明确区分两个层次的发现：

1. 当前结果支持监督式 closed-set reranking 能改善固定基础检索器的候选排序；
2. 当前结果不支持 relative interaction 已经具有独立、普遍或稳定的性能优势，因为容量匹配的 pointwise 对照在主要 R@1/MRR 汇总中略高。

本轮优先提升科学问题、方法机制和结果解释的连贯性，不通过增加审计材料或防御性声明来弥补方法叙事。

## 2. 当前证据与问题定位

### 2.1 已有、可以直接写入正文的证据

- `paper/main.tex` 和 `paper/main_cn.tex` 已定义固定候选池、完整池 coarse scoring、coarse top-40 relative refinement、无 rank、无 positive forcing、pair antisymmetry 和候选置换等变性。

  \(p_{ij}=g(\rho_{ij})-g(\rho_{ji})\)

## 4. 具体内容设计

### 4.1 标题、摘要与引言

标题和摘要应避免让读者预期 relative 必然优于 pointwise。摘要按“问题—方法—受控比较—发现—边界”组织：

1. MS/MS 候选池中存在 hard candidates，基础跨模态相似度未必能完成列表内排序；
2. 本文研究固定候选池内的 supervised closed-set reranking；
3. 提出 rank-free、no-forcing、coarse-to-fine 的 spectrum-conditioned relative candidate module；
4. 使用容量匹配 pointwise scorer 检验候选关系建模是否提供额外信息；
5. 报告两种监督 reranker 均改善 base，但 pointwise 在主要 R@1/MRR 汇总略高，relative 的独立收益尚未确立；
6. 明确本文贡献是方法框架和受控机制分析，而不是 SOTA 或 relative 优势声明。

引言末尾的贡献改为：

- 提出固定候选池内的非生成式、监督式 coarse-to-fine reranking framework，并显式分离候选 coverage 与列表内排序；
- 形式化 spectrum-conditioned、rank-free、pair-antisymmetric、permutation-equivariant 的 relative candidate module，并设置容量匹配的 pointwise control；
- 在 MassSpecGym 的 mass 和 formula-conditioned 候选池上，分析监督 reranking 的收益及 relative interaction 相对 pointwise scoring 的适用边界。

### 4.2 方法章节：从工程性质提升为可检验的机制假设

在 relative module 小节中补充一段简短理论解释：

- 普通有向 pair scorer 可以给同一候选对产生相互矛盾的两个方向；差分构造强制 \(p_{ij}=-p_{ji}\)，使一个候选对的偏好方向在表示层面一致；
- 该性质适合表达“候选 A 相对于候选 B 更符合当前谱图”的局部偏好，并与 pairwise/listwise 学习目标相容；
- 对候选列表做共同置换时，候选特征、pair preference 和最终分数共同置换，说明模型不依赖候选在张量中的任意槽位；
- 这些性质约束函数形式，但不保证全局无 cycle、不保证 hard-negative discrimination，也不保证相对于 pointwise 的指标提升；这些问题必须作为待验证假设，而不是理论定理之外的性能结论。

可增加一个不超过半页的“设计假设与可检验后果”段落或小表，列出：

| 设计 | 可直接保证的性质 | 当前论文允许的解释 |
|---|---|---|
| pair difference | pair antisymmetry | 方向一致的局部偏好表示 |
| shared candidate operations | permutation equivariance | 不依赖任意候选槽位 |
| no rank | 不把 base rank 作为显式特征 | 减少对候选顺序先验的依赖 |
| coarse-to-fine | 仅对 coarse top-40 做二次关系计算 | 控制关系模块的结构复杂度 |

补充 pointwise control 的作用：它使用相同 absolute branch 和近似参数规模，因而将“监督 residual scoring 的收益”与“候选关系本身的额外收益”分开检验。

### 4.3 相关工作与方法定位

保留 JESTR、GLMR、learning-to-rank、set/candidate interaction 的现有引用，但将比较表改成机制定位表，不写未经协议匹配的性能排序。明确本文解决的空缺是：在固定 cross-modal candidate pool 上，研究非生成式第二阶段的候选重排序和 candidate interaction，而不是替代生成式方法或复现外部 benchmark。

### 4.4 实验与结果

- 主结果段首先回答“监督 reranking 是否改善 base”，再回答“relative 是否超过 pointwise”；两条结论分开写。
- 直接保留 relative 略低于 pointwise 的事实，不使用“comparable”或防御性长句掩盖差异，也不把差异写成显著性结论。
- 将已有 spectrum-shuffle、信息源控制和 difficulty strata 合并为“descriptive mechanism analysis”，只解释模型依赖哪些输入和在哪些 query 上可能有效，不写成因果消融或普适 hard-negative 结论。
- 在结果小节增加一小段“适用边界”：relative 更像一个可研究的候选关系机制，而当前结果尚不能证明它是默认最优的排序器。
- 如保留效率内容，只在方法/附录报告结构复杂度；只有当已有 `efficiency_breakdown.json` 与当前论文模型、checkpoint、候选规模和硬件范围逐项一致时，才加入一行明确标为 fixed-hardware forward-only reference，并同时说明不含数据加载、alignment 和端到端部署。

### 4.5 化学解释与案例分析的处理

本轮不凭空增加 case study。正文只保留当前证据能支持的领域解释：formula-conditioned 是已知分子式条件下的闭集检索；模型输入是冻结谱图/分子 embedding、base score 和候选关系特征，不直接观察 raw fragment peaks 或显式分子式。

若作者后续确认开展 case study，应在本计划中新增执行记录和证据来源，至少固定 query、候选结构身份、峰列表/结构差异、reranker 前后排名及人工化学解释；否则仅在 Future Work 中写为待研究方向，不写入当前结果。

### 4.6 Discussion、Limitations 与 Conclusion

Discussion 只保留三个问题：

1. supervised second-stage reranking 对固定候选列表的价值；
2. relative interaction 没有超过容量匹配 pointwise 时说明了什么；
3. 结论受 pilot 规模、单 alignment checkpoint、saved-embedding evaluation、closed-library 和未复现外部 baseline 等边界如何限制。

将重复的“不 claim SOTA/显著性/稳定性/部署 latency”合并为一段自然的证据边界说明，详细协议仍指向 Appendix A/D。结论应写成：本文提出并分析了一个方法框架；当前证据支持监督 reranking 的框架级有效性，但不支持 relative module 独立且普遍优于 pointwise 的结论。
