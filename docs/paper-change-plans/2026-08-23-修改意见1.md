# 一、进一步明确论文的核心科学问题，调整论文贡献定位

目前论文最大的不足在于：**论文提出的方法创新性与实验结果之间存在一定张力。**

论文标题和方法描述容易使读者形成一种预期，即 spectrum-conditioned relative reranking 能够显著优于传统 pointwise ranking 方法。然而实验结果显示：

- relative model 在主要指标 R@1 和 MRR 上略低于 capacity-matched pointwise baseline；
- 实验并未证明 candidate interaction 机制具有稳定、独立的性能优势。

因此，当前论文如果继续强调“提出一种更优的 reranking 方法”，容易受到审稿人的质疑。

建议重新调整论文定位：

不要将主要贡献表述为：

> 提出一种优于 pointwise 方法的 relative reranking 模型。

而应调整为：

> 系统研究候选关系建模机制在 MS/MS 分子检索重排序任务中的作用，并证明 supervised reranking 有效，同时分析 relative interaction 相对于 pointwise scoring 的适用边界。

换言之，这篇论文真正的价值不一定在于提出一个性能领先的方法，而在于回答一个重要研究问题：

**“在化学候选检索场景中，引入候选间关系建模是否一定能够带来收益？”**

目前实验实际上已经支持这一更加谨慎且更有研究价值的结论，应进一步强化。

# 二、加强方法创新性的理论阐释

目前 relative candidate module 的设计具有一定合理性，例如：

- antisymmetric pair preference；
- permutation equivariance；
- rank-free design。

但是，这些特点目前更多停留在工程描述层面，理论分析仍显不足。

建议进一步补充以下内容：

## 1. 加强 antisymmetric mechanism 的理论解释

论文指出：

\[
p_{ij}=g(\rho_{ij})-g(\rho_{ji})
\]

因此：

\[
p_{ij}=-p_{ji}
\]

这一设计保证了 pair preference 的反对称性。

但是，需要进一步回答：

- 为什么该性质对于 MS/MS molecule retrieval 特别重要？
- 它相比普通 pairwise loss 有什么优势？
- 是否能够减少 ranking inconsistency？
- 是否能够提高 hard negative discrimination？

建议增加理论分析或实验验证，例如：

- 比较普通 pairwise scorer 与 antisymmetric scorer；
- 分析 ranking cycle 数量变化；
- 分析 hard negative 场景下的稳定性。

# 三、增加对实验规模和稳定性的验证

目前实验设计较为严谨，但实验规模仍然限制了结论的普适性。

论文当前实验存在以下限制：

1. reranker training 仅使用 5000 training queries；
2. 仅使用三个 reranker seeds；
3. 依赖单个 alignment checkpoint。

这些设置可以作为 pilot experiment，但不足以支撑较强的结论。

建议：

## 1. 扩大训练数据规模

建议至少补充：

- 使用完整 MassSpecGym training split；
- 或提供不同训练规模实验：

例如：

| Training queries | Performance |
|-|-|
| 5k | |
| 20k | |
| Full dataset | |

分析 relative module 是否随着数据规模增加而体现优势。


## 2. 增加 alignment-level variance

当前 seed variation 只反映 reranker 变化，而没有反映第一阶段 embedding 学习的不确定性。

建议：

训练多个 spectrum-molecule alignment checkpoint，并报告：

- mean；
- standard deviation；
- confidence interval。


这样可以增强结论可靠性。

# 四、补充更有解释力的化学案例分析

当前实验主要依赖：

- Recall@k；
- MRR；
- aggregate statistics。

这些指标能够说明模型性能变化，但无法解释模型为什么有效。

对于 MS/MS 任务，仅有机器学习指标是不够的，需要体现化学意义。

建议增加 case study：

选择若干：

- isomers；
- highly similar fragmentation molecules；
- cosine similarity difficult cases。

展示：

第一阶段：

candidate A > candidate B


但 reranker：

重新判断：

candidate B 更符合 spectrum。


进一步解释：

- 哪些 fragment peaks 提供信息？

- 为什么 pointwise 不容易区分？


这一部分会显著增强论文的生物信息学价值。

# 五、完善与现有方法的比较

目前论文没有直接比较 JESTR、GLMR 等方法，虽然作者解释了由于 candidate construction 和 evaluation protocol 不同，不适合直接比较。

这一解释合理，但对于论文影响力而言仍然不足。

建议至少增加以下之一：

## 方案1：

在相同 MassSpecGym candidate pool 下重新实现一个公开 baseline。

例如：

- JESTR-style cosine ranking；
- fingerprint-based retrieval；
- candidate similarity reranking。


## 方案2：

增加机制层面对比，而非性能对比：

例如：

| Method | Candidate interaction | Generation | Rank objective |
|-|-|-|-|
| JESTR | No | No | Contrastive |
| GLMR | Yes | Yes | Generation-based |
| Ours | Yes | No | Ranking-based |

并进一步讨论：

你的方法解决的是哪个具体空缺。

# 六、增加效率分析，说明模型实际应用价值

目前 relative model 的计算复杂度高于 pointwise：

- pointwise：

\[
O(Kd)
\]

- relative：

\[
O(K_r^2d)
\]

虽然 K_r=40 时计算仍可接受，但实际应用中 MS/MS annotation 通常需要处理大量 spectra。

因此建议补充：

- inference time；
- GPU memory；
- throughput；
- candidate number scaling。


例如：

测试：

K=40,80,160,256

观察：

accuracy-cost trade-off。


如果 relative model 性能没有明显优势，而计算成本明显增加，需要进一步讨论其适用场景。

- Limitations。

1. 为什么这个问题重要；
2. 为什么 candidate interaction 值得研究；
3. 实验发现带来了什么新的认识。


论文应该从“避免被误解”转向“主动提出科学发现”。

这样的贡献表述更加符合实验事实。
