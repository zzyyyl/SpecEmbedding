## 使用流程

1. 复制 [模板](TEMPLATE.md)，命名为 `YYYY-MM-DD-简短主题.md`，初始状态为 `未执行`。
2. 写明证据、范围、具体修改、引用核验、实验边界和验证方案；修改论文前设为 `执行中`。
3. 在同一计划内更新执行记录。实质偏差设为 `已偏离待确认`，暂停相关工作并等待确认。
4. 验证、双语编译和实质修改提交完成后，回填 commit，设为 `已执行`，再单独提交计划归档。
   归档 commit 无需自我引用；暂停中的计划不能因文档清理被标为完成。
