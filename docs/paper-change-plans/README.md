# 论文修改计划书

本目录专门保存 SpecEmbedding 论文较大改动的计划、执行进度与验收记录。详细强制规则见仓库根目录的 [`AGENTS.md`](../../AGENTS.md)。

## 使用流程

1. 从 `TEMPLATE.md` 创建 `YYYY-MM-DD-简短主题.md`。
2. 完整填写背景、证据、范围、引用核验、步骤和验证方案，初始状态设为 `未执行`。
3. 真正修改论文前把状态改为 `执行中`。
4. 按步骤执行并实时更新复选框、证据和偏差记录。
5. 若计划出现实质性偏差，改为 `已偏离待确认` 并暂停相关修改，待用户确认后继续。
6. 全部修改与验证完成后，先提交论文实质修改；再回填该 commit、把计划设为 `已执行`，并用独立的文档 commit 归档计划。归档 commit 无需自我引用。

状态必须显式写在计划开头，以便不打开 Git 历史也能判断计划是否已经执行。

## 建议命名

```text
2026-08-01-related-work-and-validity.md
2026-08-15-metric-protocol-correction.md
```

不要在本目录保存实验产物、论文 PDF 或通用项目说明。
