# 下游谱图的有符号差值分支

该组件已列为[A07候选方案](../attempt_7.md)，尚未作为正式实验启用。A06仍按其固定源码
与配置运行；A07的parent和最终配置指纹须在A06完成审计后绑定。

## 假设与实现

原峰表示单独编码m/z和强度。新增分支显式计算每个峰的`precursor_mz - fragment_mz`，
以64维sin/cos Fourier特征和1维母离子标记输入`65 → 128 → 512`的GELU MLP，
将输出残差加到原峰表示，再走原Transformer、mean pooling与输出头。以默认512维峰
表示计算，增加74,496个可训练参数；没有新增Transformer层或两两峰注意力矩阵。
末层从零初始化，避免在初始化时扰动同权重的原谱图编码器输出；这不保证优化效果更好。
新分支会消耗初始化随机数，不能据同一seed声称整个双塔的其余权重逐位一致。

差值不裁零、不取绝对值，不删负差值碎片，也不根据分子候选或真值分子式构造特征。
它是m/z差值，未经电荷/加合物换算，不能无条件称为中性质量损失。母离子固定为token0；
相同m/z的碎片仍与母离子角色不同。padding不进入特征、注意力键或池化，非有限有效峰
和缺失母离子直接失败。完整输入范围及限制见[优化索引D18](../analysis/massspecgym_optimization.md)。

`SpecEmbedding/models_precursor_delta.py`独立定义下游子类，未修改预训练使用的
`SpecEmbedding/models.py`。GINE和指纹两种分子塔均通过显式构造配置支持该分支，
checkpoint保留完整设置并严格重载；当前入口只允许随机初始化的正式全量训练和完整检索
验证，不接受预训练权重的部分加载。新模型的收益、GPU耗时与显存均待正式实验。

## 配置与启动条件

参数集中在`params.yaml`的`precursor_delta_encoder`，该段本身不启用模型。准备未来新运行
配置时，显式将整段复制到`model.spec_encoder.precursor_delta`；不带此键仍构造原模型，
空值、缺失构造参数或拼错字段会失败。初始波长范围为0.01至10000 m/z单位，按对数均匀分布；
这是候选设计设置，不是已验证的最优参数。

GINE候选运行需指定`--checkpoint-model-config`，指纹候选已自动使用该路径，确保比较
baseline按照自己的selection构造。既定seed42、完整194,119条训练谱图、19,423条有效
验证query、候选顺序、二维身份、自然负例、GPU等待和外部存储规则继续适用；不在本次
组件准备中同时改变batch、学习率或负例数。正式实验只能使用新的干净固定源码和运行目录。

原始token、m/z、增强、候选索引、分子图或固定Morgan位值未改变，因此当前固定输入缓存
不因增加此模型分支而失效；不存在可跨模型权重复用的已学习谱图/分子embedding缓存。
每轮验证仍完整重新编码候选。未来若修改tokenizer、图/指纹构造或输入来源，必须使对应
缓存失效并重建，保留仍被活跃任务引用的文件及历史回执。

## 验证边界

合成CPU检查覆盖负值和母离子角色、padding及碎片排列、两次优化后分支及两塔梯度、
GINE/指纹权重严格重载、原模型默认构造的权重/RNG/输出一致性，并复用两种分子塔的
完整训练入口测试检查逐轮query覆盖和候选记录。2026-09-10主机全仓539通过、1跳过、
1个既有内部路径审计失败；Ruff、compileall及diff检查通过，详细执行边界见阶段计划。
这些不是MassSpecGym正式训练结果，未新增attempt成绩。
