\begin{abstract}
串联质谱（MS/MS）是非靶向代谢组学中的关键分析技术，但由于候选分子之间存在质量、
分子式和碎片模式上的高度相似性，从实验谱图中准确注释未知小分子仍然具有挑战性。
本文将 MS/MS 分子注释建模为一个面向生物信息学的数据挖掘问题：给定一个实验谱图，
模型需要从大规模化学空间中检索并排序潜在候选分子。我们提出
\method{}，一个两阶段的谱图-分子检索与重排序框架。该框架首先学习谱图和分子的
共享嵌入表示，用于粗粒度候选检索；随后引入轻量级 listwise 分子重排序模块，在
初始 top-$K$ 候选内部进一步优化排序。重排序模块综合利用谱图嵌入、分子嵌入、
基础检索分数、原始排名以及候选间上下文信息，以区分质量或分子式约束下的 hard
candidates。我们将在多个代谢组学基准数据集上验证该方法，并分析候选召回上界、
候选集构造协议以及重排序模块各组成部分的贡献。
\end{abstract}

\noindent\textbf{关键词：}
串联质谱；代谢物注释；分子检索；表示学习；学习排序；生物信息学数据挖掘

\section{引言}

非靶向代谢组学旨在从复杂生物样本中发现和解释小分子代谢物。MS/MS 谱图能够反映
分子的碎裂模式，因此被广泛用于小分子注释。然而，在真实场景中，大量实验谱图无法
被可靠注释。主要原因在于，不同分子可能具有相近的前体质量、相同的分子式或相似的
碎片峰模式，导致仅依赖传统谱图匹配或简单相似度检索难以区分结构相近的候选分子。

从数据挖掘角度看，MS/MS 分子注释可以被视为一个大规模候选检索与排序问题。给定
一条实验谱图，模型需要在庞大的候选分子空间中找到真实分子，并将其排在尽可能靠前
的位置。近年来，深度学习方法开始利用谱图编码器、分子图编码器或联合表示学习模型，
将谱图与分子映射到同一嵌入空间，并通过嵌入相似度进行高效检索。这类方法能够支持
大规模候选搜索，但在 top-ranked 结果中仍常出现大量 hard negatives。这些负候选
与真实分子在结构、质量或分子式上高度相近，仅依赖基础嵌入相似度往往不足以完成精细
区分。

基于上述观察，本文提出 \method{}，一个候选约束的 MS/MS 分子重排序框架。该方法
首先利用谱图-分子对齐模型完成粗检索，得到每条谱图对应的 top-$K$ 候选分子；随后
使用 listwise 分子重排序模块，对这些候选进行二次打分和排序。需要强调的是，重排序
模块不生成新的分子，也不在重排序阶段访问完整分子库，而是专注于提升已有候选集合内
真实分子的相对排名。

\paragraph{本文贡献。}
本文的主要贡献包括：

\begin{itemize}
  \item 将 MS/MS 分子注释明确建模为候选约束的生物信息学数据挖掘任务，并在实验中
  显式分析候选召回上界对最终注释性能的影响。
  \item 构建谱图-分子联合表示学习框架，用于从 MS/MS 谱图中进行粗粒度候选分子检索。
  \item 设计 listwise 分子重排序模型，在固定 top-$K$ 候选内部建模候选间相对关系，
  从而改善 hard candidates 的排序质量。
  \item 通过结构、特征、损失函数和候选集协议等消融实验，系统分析重排序模块的有效性
  与适用边界。
\end{itemize}

\section{相关工作}

\paragraph{基于 MS/MS 的分子注释。}
传统分子注释方法通常依赖谱图库搜索、碎裂树推断、分子指纹预测或基于规则的候选筛选。
这些方法在已有标准谱图库覆盖的情况下较为有效，但面对未知分子、低覆盖率谱图库或
结构相近的同分异构候选时，仍然存在明显困难。近年来，深度学习模型被用于从 MS/MS
谱图预测分子指纹、结构相似度或候选排序结果，为大规模代谢物注释提供了新的解决思路。

\paragraph{谱图与分子的表示学习。}
表示学习方法试图将 MS/MS 谱图和分子结构映射到可比较的向量空间。谱图侧通常采用
Transformer、CNN 或基于峰列表的编码器；分子侧则常使用分子图神经网络、SMILES
编码器或预训练分子表示。通过对比学习或度量学习，模型可以学习谱图-分子之间的匹配
关系，并利用向量相似度完成高效检索。

\paragraph{生物信息学中的学习排序。}
学习排序方法已经广泛应用于信息检索、推荐系统和生物信息学任务。与 pointwise 方法
独立评估每个候选不同，listwise 方法直接建模同一 query 下候选集合的相对顺序。对于
MS/MS 分子注释而言，同一谱图下的候选分子通常具有相似质量或分子式，因此候选之间
的相对差异本身包含重要信息，这使得 listwise reranking 具有较强的适用性。

\section{问题定义}

记 $s$ 为一条 MS/MS 谱图，$m$ 为候选分子。候选分子可以由分子图、SMILES 或其他
结构表示给出。给定候选分子数据库 $\mathcal{D}$，分子注释的目标是使真实分子
$m^{+}$ 在所有候选中排名尽可能靠前：

\begin{equation}
  \operatorname{rank}(m^{+} \mid s, \mathcal{D}) \rightarrow 1.
\end{equation}

在实际代谢物注释流程中，候选分子集合通常由实验可得信息约束，例如前体质量、加合物
类型或分子式。因此，对每条谱图 $s$，我们定义候选集合
$\candidates_s \subseteq \mathcal{D}$。本文中的重排序任务是在 $\candidates_s$
内部优化候选分子的相对顺序，而不是恢复初始候选集中不存在的真实分子。因此，最终性能
受到候选生成阶段召回率的上界约束。该设定有助于将粗检索失败和重排序失败区分开来。

\section{方法}

\subsection{总体框架}

\method{} 采用两阶段流程。第一阶段为谱图-分子对齐模型，将谱图和分子映射到同一嵌入
空间，并基于嵌入相似度检索 top-$K$ 候选。第二阶段为分子重排序模块，在每条谱图对应
的候选集合内部建模候选间关系，并输出新的排序分数。

\subsection{谱图-分子对齐模型}

基础模型分别编码 MS/MS 谱图和候选分子。给定谱图 $s$，谱图编码器输出向量 $\zs$；
给定分子 $m$，分子编码器输出向量 $\zm$。二者经过归一化后，通过内积计算基础检索
分数：

\begin{equation}
  b(s, m) = \zs^{\top}\zm.
\end{equation}

对于每条谱图，基础模型保留分数最高的 top-$K$ 个候选分子，并记录每个候选的基础
分数 $b_i$ 与原始排名 $r_i$。这些信息随后作为重排序模块的输入。

\subsection{分子重排序模型}

对于 top-$K$ 候选集合中的第 $i$ 个候选分子 $m_i$，我们构造谱图-分子 pairwise
特征：

\begin{equation}
  \mathbf{x}_i =
  [\zs,\ \mathbf{z}_{m_i},\ \zs \odot \mathbf{z}_{m_i},\
  |\zs - \mathbf{z}_{m_i}|,\ b_i,\ \mathbf{e}(r_i)],
\end{equation}

其中，$\mathbf{z}_{m_i}$ 表示候选分子嵌入，$b_i$ 表示基础检索分数，$r_i$ 表示
基础排名，$\mathbf{e}(r_i)$ 为可学习的 rank embedding。该特征同时包含谱图信息、
分子信息、二者的匹配关系以及基础检索模型提供的排序先验。

随后，pairwise 特征经过多层感知机映射到隐藏空间：

\begin{equation}
  \mathbf{h}_i = \operatorname{MLP}(\mathbf{x}_i).
\end{equation}

为了利用同一谱图下候选分子之间的相对关系，我们将
$[\mathbf{h}_1,\ldots,\mathbf{h}_K]$ 输入 Transformer Encoder：

\begin{equation}
  [\tilde{\mathbf{h}}_1,\ldots,\tilde{\mathbf{h}}_K]
  = \operatorname{Transformer}([\mathbf{h}_1,\ldots,\mathbf{h}_K]).
\end{equation}

该模块使模型能够在候选集合内部进行 listwise 建模，而不是孤立地判断单个候选。最终，
模型通过 score head 预测每个候选的残差分数 $\Delta_i$，并与基础检索分数融合：

\begin{equation}
  s_i = \alpha b_i + \Delta_i,
\end{equation}

其中 $\alpha$ 为可学习标量，用于控制基础分数与重排序修正项之间的权重。最终排序结果
由 $s_i$ 降序排列得到。

\subsection{训练目标}

设真实分子在候选集合中的索引为 $y$。我们首先使用 listwise cross-entropy 损失优化
真实分子的排序位置：

\begin{equation}
  \mathcal{L}_{\text{CE}}
  = -\log \frac{\exp(s_y)}{\sum_{i=1}^{K}\exp(s_i)}.
\end{equation}

此外，我们引入 pairwise ranking loss，鼓励真实分子的分数高于其他负候选：

\begin{equation}
  \mathcal{L}_{\text{pair}}
  = \frac{1}{K-1}\sum_{i \neq y}
  \log \left(1 + \exp(s_i - s_y + \gamma)\right),
\end{equation}

其中 $\gamma$ 为 margin。最终训练目标为：

\begin{equation}
  \mathcal{L} = \mathcal{L}_{\text{CE}} +
  \lambda \mathcal{L}_{\text{pair}}.
\end{equation}

\section{讨论}

\method{} 的优势在于将大规模检索与精细排序解耦：基础模型负责从分子库中召回候选，
重排序模块则专注于 top-$K$ hard candidates 的相对排序。然而，该方法也存在明确
边界。首先，reranker 不能恢复初始候选集中不存在的真实分子，因此其最终性能受到候选
生成阶段召回率限制。其次，候选集构造协议会显著影响结果解释。如果候选集由测试标签
反推得到，则实验只能被解释为 oracle candidate setting，而不能被视为真实开放库检索。
因此，在面向生物信息学数据挖掘的投稿中，需要特别强调非 oracle 候选构造、跨数据集
泛化和真实候选库规模下的效率分析。

\section{结论}

本文提出 \method{}，一个面向 MS/MS 代谢物注释的两阶段候选检索与重排序框架。该方法
首先通过谱图-分子联合表示学习完成粗粒度候选检索，然后利用 listwise 分子重排序模型
在 hard candidates 中进行精细区分。后续工作将进一步完善非 oracle 候选集构造、
跨数据集泛化实验以及与更大规模分子数据库的集成。
