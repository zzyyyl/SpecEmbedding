\begin{abstract}
串联质谱（MS/MS）是代谢组学中的关键技术，但由于不同分子可能具有相近的前体质量、
相同的分子式或相似的碎片模式，从实验谱图中准确注释未知小分子仍然具有挑战性。本文
将 MS/MS 代谢物注释建模为一个面向生物信息学的数据挖掘问题：给定一条实验谱图和候选
分子库，模型需要在大规模化学空间中挖掘并排序最可能的真实分子。我们提出
\method{}，一个两阶段候选约束框架。该框架首先学习谱图和分子的共享嵌入表示，用于
粗粒度候选检索；随后引入轻量级 listwise 分子重排序模块，在 hard candidates 内部
优化排序。重排序模块综合利用谱图嵌入、分子嵌入、基础检索分数、排名嵌入和候选间
上下文信息，在不生成新分子结构的情况下提升精细排序能力。当前 MassSpecGym 初步实验
显示，在质量约束和分子式约束候选库上，重排序均能显著提升 Top-1 accuracy 和 MRR。
本文进一步强调非 oracle 候选构造、候选召回上界和消融实验协议，使工作更贴合 ADMA
中 ``Data mining for bioinformatics''、深度数据挖掘模型和 benchmark evaluation 等主题。
\end{abstract}

\noindent\textbf{关键词：}
生物信息学数据挖掘；串联质谱；代谢物注释；分子检索；学习排序；表示学习

\section{引言}

非靶向代谢组学旨在从复杂生物样本中发现和解释小分子代谢物。MS/MS 谱图能够反映分子
的碎裂模式，因此被广泛用于小分子注释。然而，在真实场景中，大量实验谱图无法被可靠
注释。不同分子可能具有相近质量或相同分子式，同一分子在不同仪器、碰撞能量和加合物
条件下也可能产生不同谱图。因此，MS/MS 分子注释不仅是一个化学问题，也是一个典型的
高级数据挖掘问题：模型需要在大规模、有噪声、且部分观测的化学空间中完成候选搜索、
筛选和排序。

近年来，神经网络方法开始学习谱图嵌入、分子嵌入或谱图-分子联合嵌入空间。这类方法
适合大规模检索，但 top-ranked 结果中仍常包含大量 hard negative molecules。这些负
候选与真实分子在质量、分子式或局部结构上非常接近，基础嵌入相似度难以直接完成精细
区分。从 ADMA 的数据挖掘视角看，该任务天然属于结构化科学数据上的 learning-to-rank
问题，且需要将候选召回质量和候选排序质量分开评估。

本文提出 \method{}，一个面向 MS/MS 代谢物注释的候选约束分子重排序框架。该框架
首先使用谱图-分子对齐模型，从质量约束或分子式约束候选库中检索 top-$K$ 候选分子；
随后使用 listwise reranker，结合谱图-分子 pairwise 特征、基础检索分数、原始排名和
候选间上下文，对候选进行二次打分。与生成式检索方法不同，我们的方法不生成新分子，
而是直接优化已有候选集合内的排序，因此推理成本更低、流程更透明，也更容易作为第二
阶段排序模块接入现有系统。

\paragraph{本文贡献。}
本文面向 ADMA2026 的 ``Data mining for bioinformatics'' 主题，主要贡献包括：

\begin{itemize}
  \item 将 MS/MS 代谢物注释明确建模为候选约束的生物信息学数据挖掘任务，并区分候选
  召回失败和候选排序失败。
  \item 提出谱图-分子检索与重排序两阶段框架，将表示学习和 listwise learning-to-rank
  结合，用于 hard molecular candidates 的精细排序。
  \item 设计非生成式分子重排序模型，利用谱图-候选匹配特征和候选间上下文，在避免
  自回归分子生成成本的同时提升排序质量。
  \item 设计面向 ADMA 的实验协议，包括官方候选库、非 oracle 候选构造、Top-$K$/MRR/MCES
  指标、推理成本比较和系统消融实验。
\end{itemize}

\section{相关工作}

\paragraph{基于 MS/MS 的分子注释。}
传统分子注释方法通常依赖谱图库搜索、碎裂规则、分子指纹预测或分子式筛选。这些方法
在参考谱图覆盖充分时有效，但容易受谱图库覆盖率限制，并且难以区分结构相近候选。近年
的 MassSpecGym 等 benchmark 推动了谱图到分子检索任务的系统评测。

\paragraph{谱图与分子的表示学习。}
深度学习方法通常使用峰序列模型、Transformer 或 binning 表示编码谱图，并使用分子图、
SMILES 或化学指纹编码分子。通过对比学习，模型可以将两个模态映射到共享空间以支持
高效检索。然而，谱图反映的是碎裂行为，分子结构反映的是化学拓扑，两者之间存在明显
模态差异，因此 top-ranked 结果中仍会出现排序错误。

\paragraph{科学数据挖掘中的学习排序。}
学习排序广泛应用于搜索和推荐任务。在 MS/MS 注释中，同一谱图下的候选分子并非独立：
它们共享质量约束、分子式约束或结构片段。因此，与 pointwise 打分相比，listwise 方法
能够利用候选集合内部的相对关系，更适合 hard candidate reranking。

\paragraph{生成式检索与非生成式重排序。}
近期生成式检索方法尝试先生成 refined molecule，再用生成分子和候选分子的分子相似度
完成重排序。这类方法能够缓解谱图-分子模态差距，但推理成本较高，并依赖生成分子的
有效性和质量。本文研究互补问题：当初始候选集合已经包含较强 hard candidates 时，
一个简单的非生成式 reranker 能达到怎样的排序效果。

\section{问题定义}

记 $s$ 为一条 MS/MS 谱图，$m$ 为候选分子。给定候选分子库 $\mathcal{D}$，分子注释
目标是使真实分子 $m^+$ 在候选中排名尽可能靠前：

\begin{equation}
  \operatorname{rank}(m^{+} \mid s, \mathcal{D}) \rightarrow 1.
\end{equation}

在实际代谢物注释中，候选库通常会根据实验元数据进行过滤，例如前体质量、加合物类型
或分子式。因此，对每条谱图 $s$，我们定义候选集合
$\candidates_s \subseteq \mathcal{D}$。本文中的重排序任务是在 $\candidates_s$
内部优化候选顺序。如果 $m^+ \notin \candidates_s$，任何 reranker 都无法恢复正确
分子。因此，实验中必须报告候选召回上界，以区分候选生成失败和排序模型失败。

\section{方法}

\subsection{总体框架}

\method{} 采用两阶段流程。第一阶段使用谱图-分子对齐模型完成粗粒度候选检索；第二
阶段在检索得到的 top-$K$ 候选内执行候选感知的 listwise reranking。

\subsection{谱图-分子对齐模型}

基础模型将谱图 $s$ 映射为向量 $\zs$，将分子 $m$ 映射为向量 $\zm$。基础检索分数由
归一化嵌入相似度计算：

\begin{equation}
  b(s, m) = \zs^{\top}\zm.
\end{equation}

对于每条谱图，基础模型保留分数最高的 top-$K$ 个候选分子，并记录每个候选的基础
分数和原始排名。

\subsection{分子重排序模型}

对于第 $i$ 个候选分子 $m_i$，我们构造 pairwise 特征：

\begin{equation}
  \mathbf{x}_i =
  [\zs,\ \mathbf{z}_{m_i},\ \zs \odot \mathbf{z}_{m_i},\
  |\zs - \mathbf{z}_{m_i}|,\ b_i,\ \mathbf{e}(r_i)],
\end{equation}

其中 $b_i$ 为基础检索分数，$r_i$ 为基础排名，$\mathbf{e}(r_i)$ 为可学习 rank embedding。
该特征同时包含谱图信息、分子信息、匹配关系和基础检索先验。随后，特征经过 MLP 投影：

\begin{equation}
  \mathbf{h}_i = \operatorname{MLP}(\mathbf{x}_i).
\end{equation}

为了建模候选间上下文，我们将 $[\mathbf{h}_1, \ldots, \mathbf{h}_K]$ 输入 Transformer
Encoder：

\begin{equation}
  [\tilde{\mathbf{h}}_1,\ldots,\tilde{\mathbf{h}}_K]
  = \operatorname{Transformer}([\mathbf{h}_1,\ldots,\mathbf{h}_K]).
\end{equation}

模型预测每个候选的残差分数 $\Delta_i$，并与基础检索分数融合：

\begin{equation}
  s_i = \alpha b_i + \Delta_i,
\end{equation}

其中 $\alpha$ 为可学习标量。最终按 $s_i$ 降序得到重排序结果。

\subsection{训练目标}

设真实分子在候选集合中的索引为 $y$。我们使用 listwise cross-entropy 优化真实分子的
排序位置：

\begin{equation}
  \mathcal{L}_{\text{CE}}
  = -\log \frac{\exp(s_y)}{\sum_{i=1}^{K}\exp(s_i)}.
\end{equation}

此外，我们使用 pairwise ranking loss 鼓励真实分子分数高于负候选：

\begin{equation}
  \mathcal{L}_{\text{pair}}
  = \frac{1}{K-1}\sum_{i \neq y}
  \log \left(1 + \exp(s_i - s_y + \gamma)\right),
\end{equation}

其中 $\gamma$ 为 margin。最终损失为：

\begin{equation}
  \mathcal{L} = \mathcal{L}_{\text{CE}} +
  \lambda \mathcal{L}_{\text{pair}}.
\end{equation}

\subsection{候选集构造协议}

为了保证公平的数据挖掘评估，主实验应使用不依赖测试标签的候选集，例如 MassSpecGym
官方 retrieval library，或由实验质量信息生成的候选。任何将测试集真实 SMILES 插入候选池
的 oracle setting 都应与主实验分开报告。每次实验应记录候选来源、$K$ 值、候选池规模和
labeled-query fraction。

\subsection{对比方法}

计划比较以下方法：

\begin{itemize}
  \item 传统谱图相似度或谱图库检索方法。
  \item MIST、CMSSP、JESTR 等神经谱图-分子检索模型。
  \item GLMR 等生成式检索方法，可使用论文报告结果或复现实验。
  \item 不使用重排序的基础谱图-分子检索模型。
  \item 不建模候选间上下文的 pointwise reranker。
\end{itemize}

\subsection{评价指标}

主要指标包括 Recall@1/5/10/20 或 Top-$K$ accuracy、MRR 和候选召回上界。我们还计划
报告 MCES@1，用于衡量 top-1 预测与真实分子的结构相似度。为了突出实际数据挖掘系统
的成本收益，还应报告基础模型、reranker 和生成式 baseline 的推理时间与显存开销。

\section{消融实验}

\subsection{重排序模块贡献}

比较基础检索模型与 \method{}，衡量第二阶段 learning-to-rank 模块带来的增益。

\subsection{重排序结构消融}

比较 Transformer reranker 和 pointwise reranker，并改变 Transformer 层数、注意力头数、
隐藏维度和 rank embedding 维度。

\subsection{输入特征消融}

分别移除基础分数、基础排名 embedding、元素乘积特征和绝对差特征，分析不同信号对 hard
candidate 区分能力的贡献。

\subsection{损失函数消融}

比较仅使用 listwise cross-entropy 与同时使用 cross-entropy 和 pairwise ranking loss
的效果。

\subsection{候选集分析}

分析质量候选、分子式候选、官方候选集、外部数据库候选以及不同 $K$ 值对结果的影响。
该实验必须同时报告候选召回上界，以免把候选召回不足误判为 reranker 失败。

\section{讨论}

\method{} 面向候选约束的生物信息学数据挖掘场景。它的主要优势是无需分子生成即可提升
hard candidate 排序质量，因此推理成本较低，容易接入现有检索流水线。它的主要限制是：
如果初始检索没有召回真实分子，reranker 无法恢复正确答案。因此，最终 ADMA 投稿需要
重点报告非 oracle 候选协议、候选召回上界、MCES@1 和推理成本，避免夸大 reranker 的适用
范围。

\section{结论}

本文提出 \method{}，一个面向 MS/MS 代谢物注释的两阶段候选检索与重排序框架。该方法
结合谱图-分子表示学习和 listwise 分子重排序，解决生物信息学中具有实际意义的数据挖掘
问题：在质量或分子式约束下对 hard molecular candidates 进行高质量排序。后续工作将
进一步完善严格非 oracle 候选构造、跨数据集泛化和大规模候选库部署。
